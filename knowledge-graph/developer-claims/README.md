## Verification Process

1. **Claim Created** - Developer asserts ownership of wallet
2. **Pending Signature** - Awaiting cryptographic signature
3. **Signature Verification** - Validate Ed25519 signature
4. **Badge Issuance** - Create developer badge in Supabase
